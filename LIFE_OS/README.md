# LIFE OS — Obsidian Vault

Personal operating system across two pillars: **HEALTH** and **WORK**. Open this folder as a vault in Obsidian.

## Start Here

1. `00_CONTROL/LIFE_OS.md` — master control file (mission, rules, hard limits)
2. `00_CONTROL/CURRENT_STATE.md` — single source of truth, updated weekly
3. `00_CONTROL/AI_CONTEXT_BRIEF.md` — copy-paste brief to onboard any AI model

## Structure

| Folder | Purpose |
|---|---|
| `00_CONTROL/` | Mission, current truth, weekly review, decision log, AI briefing |
| `01_HEALTH/` | Nutrition, training, longevity, peptide research (⚠️ medical review required), bloodwork, health log |
| `02_WORK/` | Coding, trading, marketing, sales, money |
| `03_PROJECTS/` | One file per product (Veridicta, Everform, Ravyn, Clario, OpenClaw) + idea parking lot |
| `04_AGENTS/` | Rules, workflows, reports, and handoff templates for AI agents |
| `05_DAILY_LOGS/` | Daily log template; daily entries named `YYYY-MM-DD.md` |
| `99_ARCHIVE/` | Dead/superseded files — nothing is ever deleted, only archived |

## Rules of the Vault

- `CURRENT_STATE.md` wins over everything else when files disagree.
- Logs are append-only. Dashboards summarize, they don't hold unique data.
- AI agents must read `04_AGENTS/AGENT_RULES.md` before touching anything.
- Health, trading, and money decisions always require human confirmation.
