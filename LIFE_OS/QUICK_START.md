# Life OS Quick Start

## Daily
1. Open `00_CONTROL/CURRENT_STATE.md`.
2. Check Next 3 Actions.
3. Create/fill today's log in `05_DAILY_LOGS/`.
4. Update only files that changed today.
5. End with tomorrow's top 3.

## Weekly
1. Run the weekly maintenance prompt (`04_AGENTS/WEEKLY_MAINTENANCE_PROMPT.md`).
2. Update `CURRENT_STATE.md`.
3. Review `DECISION_LOG.md`.
4. Kill weak priorities.
5. Pick next week's top 5.

## Rule
The system only works if the files reflect reality.
