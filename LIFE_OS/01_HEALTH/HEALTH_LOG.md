# HEALTH LOG

> Append-only event log for anything health-related that isn't routine daily tracking:
> symptoms, injuries, illness, intervention starts/stops, adverse effects, doctor visits.
> Routine daily data (sleep, weight, food) lives in daily logs. Newest entries at top.

---

## Entry Template

```markdown
## YYYY-MM-DD — [Event title]
- Type: (symptom / injury / illness / intervention start / intervention stop / adverse effect / doctor visit / test)
- Details:
- Severity (0-10):
- Action taken:
- Follow-up needed: (none / monitor / doctor question added / ⚠️ REQUIRES MEDICAL REVIEW)
```
