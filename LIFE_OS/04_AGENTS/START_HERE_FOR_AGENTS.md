# Start Here For Agents

Before doing any work, read these files in order:

1. `00_CONTROL/LIFE_OS.md`
2. `00_CONTROL/CURRENT_STATE.md`
3. `04_AGENTS/AGENT_RULES.md`
4. The specific domain file for your task:
   - Health task → `01_HEALTH/HEALTH_DASHBOARD.md`
   - Coding task → `02_WORK/CODING.md`
   - Trading task → `02_WORK/TRADING.md`
   - Marketing task → `02_WORK/MARKETING.md`
   - Project task → relevant file inside `03_PROJECTS/`

## Required behavior

- Do not overwrite master files without explaining why.
- Use small diffs.
- Update `04_AGENTS/AGENT_REPORTS.md` after every meaningful task.
- List risks.
- List decisions needed from G.
- Never claim something is complete unless verified.
- Health, trading, money, legal, and medical decisions require human confirmation.

## Standard output after work

Every agent must end with:

- Files read:
- Files changed:
- What changed:
- Verification:
- Risks:
- Next recommended action:
- Needs G decision:
