# ARCHIVE

Dead projects, superseded files, and old logs land here. Nothing in the vault is ever deleted — it's moved here instead.

## Rules

- Prefix archived files with the date they were archived: `YYYY-MM-DD_FILENAME.md`.
- Add a row to the index below when archiving.
- Agents: archiving a file counts as a change — log it in `04_AGENTS/AGENT_REPORTS.md`.
- Nothing in this folder is current truth. Never load archive content into [[CURRENT_STATE]] or dashboards.
